npa.workspace — Filesystem Plugin

Overview

The npa.workspace plugin provides a managed filesystem area — the workspace — where plugins and applications can create projects, folders and files. The workspace root is configured through the WORKSPACE_LOC environment variable (defaults to ./). The service is available as workspace:
let workspace = plugin.getService('workspace');
File and project operations emit events on the broker service: workspace.project.created, workspace.folder.created, workspace.file.created, workspace.file.updated.

Service Name

'workspace'

Methods

getProjects(filter?)

Returns all projects in the workspace as an array of project descriptor objects. An optional filter object can narrow results by name or type.

getProject(name)

Returns the project descriptor for the named project, or null if it does not exist.

createProject(projectInfo)

Creates a new project folder and writes its .project descriptor file. projectInfo must contain at least name and type.

deleteProject(name, user)

Deletes a project and all its contents. Only the project owner or an admin can delete a project. Throws if the caller is not authorised.

createFolder(project, relativePath)

Creates a folder (and any missing parent folders) inside a project. Returns the workspace-relative path of the new folder.

createLocalFile(relativeFileName, project, content, options?)

Creates a file inside a project with the given text content.

setFileContent(workspaceRelativePath, content, options?, callback?)

Writes (or overwrites) the content of an existing file. Options: recursive (create missing parent folders), encoding, suppressEvent (skip broker notification). An optional callback is called after the write stream closes.

appendToFileContent(workspaceRelativePath, content, options?)

Appends text content to an existing file.

folderContent(relativePath, showHiddenFiles?)

Returns the contents of a folder as an array of entries with name, type ("file" or "directory"), size, lastModified and created.

deleteResource(path)

Deletes a file or directory (recursively) at the given workspace-relative path.

Usage Example

 1. let workspace = plugin.getService('workspace');
 2. 
 3. // create a project
 4. workspace.createProject({ "name": "myProject", "type": "general" });
 5. 
 6. // create a subfolder
 7. workspace.createFolder("myProject", "src/utils");
 8. 
 9. // write a file
10. workspace.createLocalFile("src/utils/helper.js", "myProject", "// helper code");
11. 
12. // overwrite its content later
13. workspace.setFileContent("myProject/src/utils/helper.js", "// updated code", {}, function() {
14.   plugin.info('File saved');
15. });
16. 
17. // list a folder
18. let entries = workspace.folderContent("myProject/src");
19. entries.forEach(function(e) { plugin.info(e.name + ' [' + e.type + ']'); });

Notes

  • All paths passed to the API are workspace-relative — never absolute paths.
  • folderContent() uses fs.readdirSync() and is synchronous.
  • Hidden files (names starting with .) are excluded by default; pass showHiddenFiles = true to include them.
  • Workspace events are only emitted when the broker service is available.
