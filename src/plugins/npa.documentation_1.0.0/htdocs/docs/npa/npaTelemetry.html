npa.telemetry — Telemetry Plugin

Overview

The npa.telemetry plugin provides an in-memory time-series store for runtime metrics. Each metric is called a dimension and holds a rolling window of data points. Dimensions are declared by any plugin via the npa.telemetry.dimension.provider extension point. The service is available as telemetry:
let telemetry = plugin.getService('telemetry');
The plugin automatically collects and stores the JVM heap usage (used.heap) every 30 seconds.

Service Name

'telemetry'

Methods

push(dimensionName, telemetryData)

Stores a new data point for the named dimension. telemetryData is a plain object — by convention it carries a timestamp (formatted string) and a count value, but any shape is accepted. The window is capped at the dimension's maxPoints value; older entries are dropped automatically.

getDataPoints(dimensionName)

Returns the full dimension descriptor including the current data array, or null if the dimension does not exist.

getDimensionList()

Returns an array of lightweight dimension descriptors (name, label, description, type, unit) without the data payload — useful for discovery.

Declaring a Dimension

 1. {
 2.   "point": "npa.telemetry.dimension.provider",
 3.   "id": "my.plugin.metric",
 4.   "name": "my.metric",
 5.   "displayLabel": "My Metric",
 6.   "description": "Count of something per interval",
 7.   "type": "int",
 8.   "unit": "",
 9.   "maxPoints": 60
10. }

Usage Example

 1. const TELEMETRY_SERVICE = 'telemetry';
 2. const MY_DIMENSION = 'my.metric';
 3. 
 4. // push a data point every 30 seconds
 5. collectMetrics = function() {
 6.   let telemetry = plugin.getService(TELEMETRY_SERVICE);
 7.   telemetry.push(MY_DIMENSION, {
 8.     "timestamp": moment().format('YYYY/MM/DD HH:mm:ss'),
 9.     "count": myCounter
10.   });
11.   myCounter = 0;
12.   setTimeout(collectMetrics, 30000);
13. }

Notes

  • Data points are stored in memory only — they are lost on server restart.
  • The maxPoints cap implements a circular buffer: when full, the oldest entry is evicted to make room for the newest.
  • Several built-in NPA plugins push telemetry automatically: npa.rest (rest.calls), npa.couchdb.adapter (database.transaction), npa.http (http.session).
