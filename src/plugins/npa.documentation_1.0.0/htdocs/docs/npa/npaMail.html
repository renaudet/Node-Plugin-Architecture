npa.mail — Mail Plugin

Overview

The npa.mail plugin sends emails via SMTP using nodemailer. It supports multiple named mail providers contributed through the npa.mail.provider extension point. The service is available as mail:
let mailService = plugin.getService('mail');

Service Name

'mail'

Methods

sendMail(providerId, from, to, subject, content, isHtml, callback)

Sends an email through the named SMTP provider.

ParameterTypeDescription
providerIdstringID of the configured mail provider
fromstringSender address (e.g. "noreply@myapp.com")
tostringRecipient address or comma-separated list
subjectstringEmail subject line
contentstringEmail body (plain text or HTML)
isHtmlbooleantrue to send as HTML, false for plain text
callbackfunction(err, response)Called on completion

Declaring a Mail Provider

Mail providers are declared in the contributing plugin's manifest.json using the npa.mail.provider extension point:
 1. {
 2.   "point": "npa.mail.provider",
 3.   "id": "my.plugin.mail.provider",
 4.   "type": "smtp",
 5.   "host": "smtp.myapp.com",
 6.   "port": 587,
 7.   "secure": false,
 8.   "username": "$SMTP_USER",
 9.   "password": "$SMTP_PASSWORD"
10. }
Field values starting with $ are resolved from environment variables at startup. The type field is used as the provider key when calling sendMail().

Usage Example

 1. let mailService = plugin.getService('mail');
 2. 
 3. let body = '<h2>Hello!</h2><p>Your report is ready.</p>';
 4. 
 5. mailService.sendMail(
 6.   'smtp',
 7.   'noreply@myapp.com',
 8.   'user@example.com',
 9.   'Your report is ready',
10.   body,
11.   true,
12.   function(err, response) {
13.     if(err) {
14.       plugin.error('Mail failed: ' + JSON.stringify(err));
15.     } else {
16.       plugin.info('Mail sent successfully');
17.     }
18.   }
19. );

Notes

  • When no username is configured, the SMTP transport is created without authentication and with TLS certificate verification disabled — suitable for internal/relay SMTP servers.
  • The SMTP transport is created and closed for each call to sendMail().
