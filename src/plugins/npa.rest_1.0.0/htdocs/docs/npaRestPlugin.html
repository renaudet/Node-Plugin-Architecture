npa.rest — REST Client Plugin

Overview

The npa.rest plugin provides a server-side HTTP client for NPA plugins. It wraps the axios library into a single, uniform API that handles GET, POST, PUT and DELETE calls, optional Basic authentication, HTTPS with self-signed certificates, and telemetry collection.

It is not a service in the NPA sense (it does not register under npa.core.service), but is accessed directly through the NPA runtime as a plugin reference:
let restPlugin = plugin.runtime.getPlugin('npa.rest');

The restContext Object

All methods accept a single restContext JSON object that fully describes the remote call. The table below lists all recognised fields:

Field Type Required Description
hoststringyesTarget hostname or IP address
portintegernoTCP port — omit to use the default (80 / 443)
uristringyesRequest path, e.g. /api/v1/resource
methodstringyesGET, POST, PUT or DELETE
securedbooleanyestrue to use HTTPS, false for plain HTTP
acceptCertificatebooleannoWhen true, accepts self-signed / untrusted TLS certificates
usernamestringnoBasic-auth username
passwordstringnoBasic-auth password
payloadobjectnoJSON body sent with POST and PUT requests
optionsobjectnoRaw axios options (e.g. custom headers)

Main Method

performRestApiCall(restContext, callback)

The single entry-point for all outbound HTTP calls. It inspects restContext.method and delegates to the appropriate internal method.

The callback follows the standard Node.js error-first convention:
function(err, response)
err is null on success; response is the raw axios response object (use response.data to access the parsed body).

Usage Example

Simple GET request

 1. let restPlugin = plugin.runtime.getPlugin('npa.rest');
 2. 
 3. let restContext = {
 4.   "host": "api.example.com",
 5.   "port": 443,
 6.   "uri": "/v1/items",
 7.   "method": "GET",
 8.   "secured": true
 9. };
10. 
11. restPlugin.performRestApiCall(restContext, function(err, response) {
12.   if(err) {
13.     plugin.error('REST call failed: ' + err);
14.   } else {
15.     let items = response.data;
16.     // process items...
17.   }
18. });

Authenticated POST request

 1. let restPlugin = plugin.runtime.getPlugin('npa.rest');
 2. 
 3. let restContext = {
 4.   "host": "internal.myapp.local",
 5.   "port": 8080,
 6.   "uri": "/api/process",
 7.   "method": "POST",
 8.   "secured": false,
 9.   "username": "admin",
10.   "password": "secret",
11.   "payload": { "input": "value" }
12. };
13. 
14. restPlugin.performRestApiCall(restContext, function(err, response) {
15.   if(err) {
16.     then('Remote call failed', null);
17.   } else {
18.     then(null, response.data);
19.   }
20. });

HTTPS with self-signed certificate

Set acceptCertificate: true when the remote server uses a self-signed or internally-issued TLS certificate that would otherwise be rejected:
1. let restContext = {
2.   "host": "192.168.1.50",
3.   "port": 9443,
4.   "uri": "/status",
5.   "method": "GET",
6.   "secured": true,
7.   "acceptCertificate": true
8. };

Typical Usage in a Servlet

A common pattern is to call npa.rest from inside a server-side servlet fragment to aggregate data from an external system before returning it to the browser:
 1. fetchExternalData = function(params, ctx, then) {
 2.   let restPlugin = ctx.runtime.getPlugin('npa.rest');
 3.   let restContext = {
 4.     "host": "data.provider.io",
 5.     "uri": "/api/metrics",
 6.     "method": "GET",
 7.     "secured": true
 8.   };
 9.   restPlugin.performRestApiCall(restContext, function(err, response) {
10.     if(err) {
11.       then('Failed to fetch metrics', null);
12.     } else {
13.       then(null, response.data);
14.     }
15.   });
16. }
17. 
18. servlet.endpoint = fetchExternalData;

Notes

  • The npa.rest plugin automatically tracks the total number of outbound calls and pushes a telemetry counter every 30 seconds to the rest.calls dimension.
  • The response object passed to the callback is the raw axios response. The parsed body is always available at response.data.
  • Errors from the HTTP layer (4xx, 5xx, network failures) are caught and forwarded as the first argument of the callback — they never throw.
